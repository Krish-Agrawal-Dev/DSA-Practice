## Key Concepts

- Fixed-size windows
- Variable-size windows
- Two pointers (left and right)
- Window invariants
- Frequency/count tracking
- Counting valid subarrays with right - left + 1
- exactly(K) = atMost(K) - atMost(K - 1)
- Frequency matching with a match counter
- Maximum-frequency tracking inside a window
- Benefit-based sliding windows

## Complexity

Most sliding-window solutions run in **O(n)** time, with **O(1)** or **O(k)** auxiliary space depending on the technique.
